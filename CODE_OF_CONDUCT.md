# Code of Conduct

verifa11y adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that link applies to every project space: issues, pull requests,
discussions, and any event or channel where someone represents the project.

In short: be respectful and constructive, assume good faith, and focus on the work. Harassment, personal attacks,
discriminatory language or imagery, and publishing others' private information are not acceptable.

This is an accessibility project. Please also be mindful of accessibility in how you communicate: describe images
and screenshots in text, do not rely on color alone in diagrams, and prefer text over video when you can.

## Reporting

Report unacceptable behavior privately to the maintainers using GitHub's private reporting for this repository
(**Security → Report a vulnerability** can be used for conduct reports too), or by contacting a maintainer listed in
[GOVERNANCE.md](GOVERNANCE.md) directly. Reports are handled confidentially.

## Enforcement

Maintainers follow the Contributor Covenant's enforcement guidelines: correction, warning, temporary ban, permanent
ban, in increasing order of severity, depending on the impact of the behavior.

# 0007. License under Apache-2.0

## Context
The prototype was MIT. Companies that would integrate verifa11y into their pipelines usually expect an explicit
patent grant.

## Decision
Relicense the code under Apache-2.0, with a NOTICE file. Third-party corpus material keeps its own license
(MPL-2.0 for axe-core fixtures, the W3C Software and Document License for the W3C BAD pages).

## Consequences
Contributions are accepted under Apache-2.0 (CONTRIBUTING.md). When the corpus moves to its own repository
(roadmap phase 4) it gets its own license terms (MIT for hand-written pages, CC-BY for adapted ones).

Installing Tern

Tern runs on Linux, macOS and Windows.

Requirements

You need Node.js 20 or later.

Install

Run the installer for your platform.

Linux

curl -fsSL https://tern.example.com/install.sh | sh
Windows
winget install tern

Verify

Check the version:

tern --version
